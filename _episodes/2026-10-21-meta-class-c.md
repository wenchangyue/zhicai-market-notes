## 本期简要回答

Meta 2026 年三季度收入增长 26%，自由现金流却是负 21.2 亿美元，同时宣布新设没有投票权的 C 类股。老岳的判断是：发 C 类股，是要钱，不交权。AI 开支已经超过公司自己赚回来的现金，往后要向市场拿钱；用 C 类股融资、发员工股、做收购，扎克伯格约六成的投票权都不会被稀释。加州富人税是次要原因：提案若通过，他可能要交一大笔税，C 类股让他卖股票交税而不丢控制权，但协议也把他锁在公司约八年。外部股东要接受的交换是：你出钱，他做主。下次看到一家公司发新股，先问钱从哪来、谁来出，权在谁手里、谁来管；出钱的人和说话的人越分越开，越要看现金流。

## 逐字稿

## P0

大家好，欢迎大家来到智财小站，我是老岳。

还没订阅的朋友，可以先点个订阅。

10 月 21 日，美东周三，Meta 收盘以后发了三季报。收入涨了四分之一多，生意比去年还好，可同一份财报里还有两条消息，比收入更值得你花时间。据报道，这是它上市以来头一回入不敷出，自由现金流是负二十多亿美元。它还宣布要发一种新股票，这种股票拿在手里不能投票。

你先想一下，一家这么能赚钱的公司，为什么要发一种不能投票的股票？

我直说：发 C 类股，是要钱，不交权。Meta 在 AI 上花的钱，已经超过它自己赚回来的现金，往后要向市场拿钱；有了 C 类股，它可以一次次发股票融资、发员工股、做收购，扎克伯格手里的投票权一点都不会被摊薄。出钱的人越来越多，说话的人始终只有一个。

有人说，这是为了躲加州的富人税、把扎克伯格留住。分析下来，这只是次要原因。按加州官方的说明，这项税看的是今年 1 月 1 日住在哪里，现在搬走也躲不掉；Meta 自己的文件里，用途排在头一条的是融资。

## P1

Meta 的钱几乎全来自广告。Facebook、Instagram、WhatsApp 免费给人用，每天有几十亿人在刷，广告主按展示次数和效果付钱。

一个卖运动鞋的商家，把钱付给 Meta，让它把广告推给合适的人。Meta 用 AI 模型判断这条广告该推给谁，推得越准，商家卖出去的鞋越多，下次愿意出的价钱就越高，广告价钱跟着水涨船高。Meta 收了广告费，再付钱给英伟达买芯片，付钱给承包商建数据中心。这一季广告卖得更多，单价也更高，所以我认为，赚钱这一头没有问题，问题全在花钱这一头。

去年同一个时候，Meta 发三季报，收入也很好，但资本开支一路往上调，股价第二天就重重跌了一回。那时候大家担心的是，这么多钱砸进 AI，什么时候能赚回来。一年过去，这个担心没有消掉，开支继续上调，这一季自由现金流转负。同一时间，加州的富人税要投票，开支、现金流和税这几个因素正好赶在了一起。

C 类股背后最要紧的原因，是 AI 开支已经超过它自己赚回来的现金，以后得向外面拿钱。我把它排在头一位，因为它量级最大、拖得最久，公司文件也把融资写在用途头一条。你感受一下这个量级：一个季度资本开支三百五十亿美元左右，比这个季度经营活动赚回来的现金还多；全年要花一千四百亿上下，公司自己的文件里也说，这个投入规模前所未有。

画面上还有三处值得留意：这一季没有回购，账上的现金已经和长期债务差不多，还计提了一大笔法律和解费用。员工比去年少了，花在算力上的钱却越来越多，手里的现金又不再宽裕，再往后只能从外面拿钱。

## P2

钱为什么会不够？AI 模型越大，算力就越贵。扎克伯格要做的是给每个人的超级智能，CFO 在电话会上说，要把用户规模扩大，就需要大量投资，而且明年还要继续积极投入。照这个节奏，我推断往后几年都还得往里填钱。

钱不够，为什么不像以前一样借债？借债要还本付息，现金已经和债务差不多，我推断再借下去，利息负担会越来越重。发普通股票不用还，可每发一次，扎克伯格手里的投票权就被稀释一点。他现在拿着六成的投票权，经济权益却只有一成多一点。出钱不多、说话算数，靠的是双层股权结构。要是每次融资都发有投票权的股票，这个结构早晚会被摊平。

无投票权的 C 类股正好绕开这个麻烦，股票照发，钱照拿，投票权一动不动。公司文件里也写了，Alphabet、OpenAI、Anthropic、SpaceX 都在大规模融资，融资环境越来越难，所以要提前把工具备好。钱不够，又不想多借，又不想交权，剩下的办法就是 C 类股。

## P3

加州的富人税排在第二。11 月 3 日加州要投票一项提案，通过的话，亿万富翁要一次性交净资产的百分之五。Meta 的文件里写着，提案要是通过，扎克伯格可能要交一大笔税，C 类股给他一条卖股票交税、又不用交出投票权的路。

说实话，我不赞成把这个安排说成是为了逃税。这项税按今年年初的居住地算，现在搬走也没用，C 类股解决的不是逃不逃，是他真要交税的时候钱从哪来。以前他卖的是带投票权的股票，卖一次控制权就少一点；以后他卖 C 类股，控制权不动。这是给他本人留的一条变现通道，排在融资后面。员工股和收购也是一样，以后给员工发股票、拿股票收购别的公司，都可以用 C 类股，同样不碰投票权。

## P4

如果你是扎克伯格，这笔交易是不是全是好处？协议其实把他锁住了。他拿到的 C 类股，只有两成能随便卖，剩下的每个季度解锁一小块，前提是他全职留在公司。算下来差不多八年才能解锁完，正好对上他承诺八年住在加州或者公司总部所在地。没解锁的 C 类股，每卖一股，就要同时卖掉或者转换一股有投票权的股票，投票权跟着往下走。文件里的原话是，他拿不到大部分 C 类股的流动性，除非相应减少投票权。

扎克伯格得到了控制权和交税的钱，代价是把自己和公司绑了八年。董事会的想法是，他最适合带公司走进下一个阶段，可又不想给他发股权激励，那样既要算成本，又会稀释所有股东，从 2013 年以后他就没拿过这类奖励，所以就用留任加锁股这一套把他绑住。

外部股东呢，手里有多少股就送多少股 C 类，经济权益一分不少，公司也能继续大胆投入，这是得。失的是，以后每次增发都在稀释他们的钱，而他们没有投票权去反对。这次的方案连股东大会都没开，持有过半投票权的股东签字同意，就通过了。员工得到的是，股票激励以后不再受投票权约束，公司发股票也更痛快。

## P5

直觉上，手里的股数多了一份，钱不变，这次送股对股东没什么影响。可 C 类股真正的作用要到以后才看得到。每发一次 C 类股融资，扎克伯格的经济权益都会再降一点，投票权却一点不降，出钱和说话的比例会越拉越大。今天是出一成多的钱、管六成的事，再融几轮，就是出更少的钱，管同样多的事。

这种做法有先例。2014 年谷歌也给股东每股送了一股无投票权的 C 类股。后来 C 类股的价格比 A 类股便宜，谷歌还因为股东诉讼和解，掏钱补偿过 C 类股的股东。市场会给没有投票权的股票打折，这是谷歌已经付过的学费。这次和谷歌也有不一样的地方：谷歌当年没有把锁股、留任、居住地和交税绑在同一份协议里，Meta 这次全都绑在了一起，扎克伯格想卖多少、什么时候卖，都要按协议走。对外部股东来说，这是一层保护，可它管的是扎克伯格卖股票，管不了公司发多少新股。

所以我更担心往后 Meta 每一次说要发 C 类股融资时，你手里的股票会被稀释多少，由别人决定，你只能看着。

## P6

反对我的人里，最站得住的理由是收入涨了四分之一多，四季度的指引还更高，广告单价在涨，说明 AI 投入已经在变成收入，这不是乱花钱。支持扎克伯格的人还会说，创始人控制让公司敢做长期投入，不用每一步都看短期股价的脸色。再说，C 类股要到明年 1 月才生效，什么时候卖、卖多少，现在都没定，也许发得很少。

理由我都认，可开头的判断我还是坚持。自由现金流转负是已经发生的事实，C 类股是一个随时可以用、不用问股东的融资工具，工具备好了，用不用是公司说了算。一家公司把花钱的权力和出钱的义务分得这么开，我的态度是谨慎。明年要是开支放缓，自由现金流转正，C 类股也没怎么增发，这三个信号同时出现，就说明公司靠自己赚的钱撑住了 AI 投入，我开头的判断就要往回收。

## P7

同行会先受到影响。文件里点名的 Alphabet、OpenAI、Anthropic、SpaceX 都在抢钱，Meta 多了一个不交权的融资工具，其他由创始人控制、又要大笔花钱的科技公司，也许会照着做，因为它们面对的是同一个难题：既要外面的钱，又不想让出决定权。你会看到越来越多公司一边讲 AI、一边发股票，谁家现金流先转正、谁家先不用再向外拿钱，往后比的就是这一点。

明年 1 月送股以后，A 类股价格会掉一半左右，图上看像是跌了一半，其实是股数翻倍，别误读成暴跌。接下来最可能的走法是，公司按需要不时发一些 C 类股，一边融资一边发员工股。要判断我说得对不对，就盯三个信号：每个季度的自由现金流，C 类股实际发了多少，以及 C 类股相对 A 类股有没有折价。

这套安排对你是好是坏，要看你是哪一类人。如果你手里有 Meta 的股票，或者长期看好它，明年 1 月你的账户里会多出同样数量的 C 类股，钱不变。你要接受的是一笔交换：你出钱，他做主，公司换来的是敢花钱的自由。往后你要关注的是增发了多少 C 类股，自由现金流有没有转正。

如果你还没买，或者想做短线，财报和送股会带来一阵波动。我认为，公司经营上的判断和买不买的判断，要分开做。经营上，收入在涨，广告在涨价，生意本身是好的；风险在开支，要是现金流连着几个季度转不回来，这个判断就不成立。至于买不买，公司变好不等于现在就能买，入场要看趋势规则：到周二收盘，它的价格还在长期均线上方，但离九月的高点回落了一截。我不报目标价，也不给买卖指令。

## P8

一家这么会赚钱的公司为什么要发不能投票的股票，答案是它要的钱已经超过自己能赚的，又不肯交出说话的权力。

以后再看到一家公司发新股，你先问两个问题：钱从哪来，谁来出；权在谁手里，谁来管。出钱的人和说话的人越分越开，你就要多看现金流，因为现金流是你手里唯一能用来判断的依据。

你愿意买一只没有投票权、公司由一个人说了算的股票吗？评论区写下你的选择。
